写博客最常用的 Markdown 语法，备忘。

### 标题

```markdown
# H1
## H2
### H3
```

### 文本

```markdown
**粗体** *斜体* ~~删除线~~
```

### 代码块

```python
print("Hello World")
```

### 链接 & 图片

```markdown
[文字](url)
![alt](image-url)
```

### 列表

```markdown
- 无序列表
1. 有序列表
```
